# Frontend - Analizador de Baches

React + TypeScript + Vite + Tailwind CSS. Ver el README en la raíz del repositorio para la arquitectura completa (frontend + backend) y las instrucciones de instalación/uso.

```bash
npm install
npm run dev      # http://localhost:5173, con proxy hacia el backend en :5000
npm run build    # genera dist/, servido por el backend Express en producción
```
